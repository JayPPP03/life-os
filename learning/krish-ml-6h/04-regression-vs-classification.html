📋 Coach's Review — common learner gaps in this topic

You haven't written notes for this topic yet. When you do, the coach checks them against this list — the things learners most often miss or get wrong here:

① Deciding regression-vs-classification by the ALGORITHM.
Decide by the OUTPUT variable: continuous number → regression; fixed categories → classification. The same algorithm family can serve either side.
② Thinking a classifier outputs numbers like a regressor.
Fit pass=1/fail=0 with a line and a student gets '0.37' — neither pass nor fail. Categories are fixed; that's why classifiers output a class (and probabilities behind the scenes).
③ Reporting accuracy on imbalanced problems.
Churn at 5%: 'always predict no' scores 95% accuracy while catching zero churners. Precision/recall (your churn model: precision +18% QoQ) are the honest metrics.
④ Calling clustering a type of classification.
Unsupervised has NO output variable y at all — it groups (segmentation) or compresses (PCA). There is no label to be 'correct' against.
⑤ Forgetting multiclass sits between binary and regression.
Pass/fail is binary; digits 0–9 is multiclass (3+ fixed categories); weight is continuous. Three different output shapes, three different setups.
⑥ Metric drift across paradigms.
Quoting R²/MAE for a classifier, or accuracy for a forecast — R²/MAE belong to regression; accuracy/precision/recall belong to classification.

🧮 Worked Mini-Project — two tiny datasets: why continuous vs fixed-category changes everything

Business problem: two questions from the same business review — 'how many calls will this agent handle next month?' (a number) and 'will this trainee pass QA?' (a label). Same supervised setup (X and y both known), opposite machinery. The video's toy pair — age→weight and study/play→pass/fail — carries both ends.

Dataset A — REGRESSION (age → weight, the video's example):

Age x (years)12162024
Weight y (kg)40525870

Step 1 — fit the line by least squares: means x̄ = 18, ȳ = 55

θ1 = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)² = (90+6+6+90) / (36+4+4+36) = 192/80 = 2.4 kg per year
θ0 = ȳ − θ1·x̄ = 55 − 2.4×18 = 11.8  →  weight = 2.4·age + 11.8

Step 2 — predict a CONTINUOUS answer: age 18 → 2.4×18 + 11.8 = 55.0 kg. Any value on the scale is allowed — that's what makes it regression.

Step 3 — score it the regression way: predictions 40.6, 50.2, 59.8, 69.4 → errors +0.6, −1.8, +1.8, −0.6 → SSres = 7.2, SStot = Σ(y−ȳ)² = 225+9+9+225 = 468

R² = 1 − 7.2/468 = 0.985  ·  MAE = (0.6+1.8+1.8+0.6)/4 = 1.2 kg — distance-based errors make sense for numbers.

Dataset B — CLASSIFICATION (study vs play hours → pass/fail, the video's example):

Step 1 — why NOT the regression line: code pass=1, fail=0 and fit a line — a new student gets a prediction like 0.37, which is neither pass nor fail. Categories are fixed, so the right shape is a boundary, not a line: pass when study − play > 0.

Step 2 — apply the boundary: new student studies 4, plays 5 → 4 − 5 = −1 < 0 → predict fail (logistic regression agrees: P(pass) ≈ 0.32 < 0.5 → fail).

Step 3 — score it the classification way: the rule gets all 5 students right → accuracy 5/5 on this toy. On real imbalanced data (churn ~5%), accuracy lies — precision/recall are the honest scores (your churn model: precision +18% QoQ, a 3x high-risk cohort).

Continuous y → regression model + R²/MAE   |   fixed-category y → classifier + accuracy/precision/recall

In [1] — REGRESSION: age → weight, fit the line
import pandas as pd
from sklearn.linear_model import LinearRegression, LogisticRegression

reg = pd.DataFrame({'age': [12, 16, 20, 24], 'weight': [40, 52, 58, 70]})
lin = LinearRegression().fit(reg[['age']], reg['weight'])
print("weight = %.1f * age + %.1f" % (lin.coef_[0], lin.intercept_))
weight = 2.4 * age + 11.8
In [2] — a continuous prediction + regression metrics
age18 = pd.DataFrame({'age': [18]})
print("predicted weight at age 18:", lin.predict(age18)[0])
print("R2 =", round(lin.score(reg[['age']], reg['weight']), 4))
predicted weight at age 18: 55.0 R2 = 0.9846

📝 Notes

This is the map of the whole ML territory — every algorithm you'll ever meet sits in one of these boxes.

  • Supervised learning: the dataset has independent features (X) and a known dependent output (y). Video example: age → weight. The model learns the mapping X → y from labeled examples.
  • Regression: supervised, output is a CONTINUOUS number. Examples: predicting a person's weight from age, house price, tomorrow's temperature, sales next month.
  • Classification: supervised, output belongs to FIXED categories. Video example: given study-hours vs play-hours → pass/fail (binary). Multiclass = more than two categories (digit recognition 0–9).
  • Unsupervised learning: no output variable at all — only features. Two main flavors:
    • Clustering — group similar items together (customer segmentation; the ad-marketing use case: target each segment with the right campaign).
    • Dimensionality reduction — compress many features into fewer while keeping the essence (PCA: 1000 features → 100).
  • Reinforcement learning — mentioned as the third paradigm: an agent learns by reward/penalty from an environment.
Supervised: (X, y) known → predict y.   Regression: y continuous.   Classification: y ∈ fixed classes. Unsupervised: X only → structure (clusters / fewer dimensions).
