📋 Coach's Review

Common learner gaps in this topic — these are the six places SVM interviews most often go wrong.

① "Support vectors are all the training points."
Only the points touching the margin planes define the boundary — below, that's (2,2) and (5,5) out of six. Delete the rest and nothing moves. That's the definition.
② Misplacing the marginal planes.
They sit at wᵀx + b = +1 and −1, with the hyperplane at 0 between them. The full street width is 2/||w|| — maximizing it ⇔ minimizing ||w||.
③ Getting C backwards.
LARGE C = strict about errors → narrow margin, memorizes outliers, overfit risk. Small C = forgiving → wider margin, tolerates violations. The lab shows the real trade: C=0.1 → train 83%/test 100%; C=100 → train 100%/test 88%.
④ Forgetting why soft margins exist.
Real data overlaps. Slack ξᵢ measures each violation and the objective ||w||²/2 + C·Σξᵢ prices them. A hard margin (zero errors) is the rare, clean-data special case.
⑤ Not knowing WHEN to reach for a kernel.
Only when data is NOT separable in the current space — the kernel lifts it a dimension (2D → 3D) where a flat plane works. Fitting a poly kernel on already-separable data is wasted complexity.
⑥ Classifying by magnitude instead of sign.
A new point's class = sign(wᵀx + b). The SIZE of wᵀx+b tells you confidence/distance from the boundary, not the class.

✍️ Solve on Paper — SVM by hand

Close the laptop. Pen and paper. The code works because this math works.

The recipe:

  1. Plot the points. Spot the support-vector candidates: each class's points nearest to the other class.
  2. Write the margin-plane equations: wᵀx + b = +1 for the closest +1 point(s), wᵀx + b = −1 for the closest −1 point(s).
  3. Solve the linear system for w and b — subtracting equations kills variables fast.
  4. Margin = 2/||w||. Verify every other point clears its margin plane (strictly beyond ±1).
  5. Classify new points by sign(wᵀx + b) — the sign, never the size.
  6. If a point invades the margin: its slack is ξ = 1 − y·(wᵀx + b), and the objective pays C·ξ for it.

Worked practice — 4 users, 2 per class (class +1 = upgraded, class −1 = not), linearly separable:

Userx₁x₂Class
A11+1 — upgraded
B33+1 — upgraded
C01−1 — not
D10−1 — not

The solve: A is the +1 point nearest the −1s; C and D are the −1 points nearest the +1s. Pin each exactly ON its margin plane:

A(1,1): w₁ + w₂ + b = +1
C(0,1):     w₂ + b = −1
D(1,0): w₁     + b = −1

C − D → w₂ − w₁ = 0 → w₁ = w₂  ·  A − D → w₂ = 2
so w = (2, 2) and b = −1 − w₁ = −3
verify every point: f(A) = 2+2−3 = +1 ✓ on the plane · f(C) = 0+2−3 = −1 ✓ · f(D) = 2+0−3 = −1 ✓
f(B) = 6+6−3 = +9 > +1 ✓ B clears the margin comfortably → B is NOT a support vector — delete it and nothing moves
||w|| = √(4+4) = √8 = 2.8284 → margin = 2/2.8284 = 0.7071 (sklearn on these 4 points: w = (2,2), b = −3, support vectors = A, C, D — same street)

Classify 2 new users by the sign:

N(2,1): f = 2·2 + 2·1 − 3 = +3 → sign + → upgraded → send the upgrade offer
N(0,0): f = 2·0 + 2·0 − 3 = −3 → sign − → not → leave on the free plan

A point invades the margin — soft margin to the rescue: user Z(1, 0.5) arrives, labelled +1, but f(Z) = 2·1 + 2·0.5 − 3 = 0: sitting exactly ON the hyperplane, deep inside the +1 side of the street. No hard margin can keep it and stay wide — so measure the violation:

ξ_Z = 1 − y·f(Z) = 1 − (+1)·0 = 1 (in margin units; the geometric distance across = ξ/||w|| = 1/2.8284 = 0.3536)
soft-margin objective: ½||w||² + C·Σξ = 8/2 + C·1 = 4 + C → at C = 1 the violation costs 1
small C: shrug, pay the 1, keep the wide street · huge C: pay anything, shove the boundary — narrow street, overfit risk

Your turn: user G(0.5, 1.5) arrives, also labelled +1. Using the SAME w = (2,2), b = −3: compute f(G), then ξ_G, then the penalty C·ξ_G at C = 1.

Attempt first, then open the full solution
f(G) = 2·0.5 + 2·1.5 − 3 = 1 + 3 − 3 = +1
ξ_G = 1 − (+1)·(+1) = 0 → penalty C·ξ_G = 0 — no violation at all

G sits EXACTLY on the +1 margin plane: perfectly legal (the plane is on the class's own side), zero cost. But note the boundary case: on a refit, G would touch the plane — meaning G would become a support vector. Only points strictly beyond +1, like B with f = +9, cost nothing AND stay out of the support-vector set.

from sklearn.svm import SVC

📝 Notes

SVM classifies by finding the best separating hyperplane — the one with the WIDEST safety margin between classes.

  • The hyperplane: wᵀx + b = 0. A new point's class = the SIGN of wᵀx + b (positive → one class, negative → the other).
  • Worked example from the video: w = [−1], b = 0 → point (−4, 0): wᵀx + b = (−1)(−4) = +4 → class A. Point (4, 4): −4 → class B.
  • Marginal planes: wᵀx + b = +1 and wᵀx + b = −1 (the two dashed lines, distance K apart). The support vectors are the points touching these planes — they alone define the boundary.
  • The objective: maximize the margin = 2/||w||, which is equivalent to minimizing ||w||. Wider margin → more confident generalization.
  • Soft margin (real data): perfect separation rarely exists. Allow errors with slack variables ξᵢ (how far each offender crosses) and minimize ||w||²/2 + C·Σξᵢ. C controls the tolerance for errors: small C = forgiving (wider margin, more violations), large C = strict (narrow margin, fewer violations, overfit risk). A HARD margin (zero errors) is the ideal-but-rare case.
  • Kernels: when data isn't separable in 2D, a kernel lifts it to a higher dimension (2D → 3D) where a flat plane CAN separate it — the 'kernel trick'.
  • SVR (assignment): regression version — the video leaves deriving the ±ε tube (predictions inside the tube incur no penalty) as homework.
  • 💡 Interview angle: 'What are support vectors?' → only the boundary-defining points matter; remove the rest and the boundary doesn't change. 'What does C do?' → error budget: big C = strict/overfit-prone, small C = tolerant/softer margin.
